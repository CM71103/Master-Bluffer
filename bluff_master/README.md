# bluff_master

Flutter client for Bluff Master. REST and Socket.IO use
`https://bluff-master-server.onrender.com` by default. For local development,
override the endpoint with `flutter run --dart-define=SERVER_URL=http://localhost:3000`
(use `http://10.0.2.2:3000` instead for an Android emulator).
